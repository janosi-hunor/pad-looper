Record and loop follow the lowest and highest key when you change octave. To set the range by hand, click a button and press that key. If "Last MIDI" doesn't change when you press a button, that button sends nothing to the computer and can't be used.

Lowest key → pad = record (hit the pad again to stop) · pad = play · highest key → pad = loop · pad again = stop · mic is recorded together with the keys · each knob = volume of the pad in the same position
No controller? Keys A–J play notes, 1–8 are pads, R = record key, L = loop key.
